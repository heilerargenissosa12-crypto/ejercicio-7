# Ejercicio 7: Squeaky Clean

- **Concepto:** Strings (Advanced) / Chars (`StringBuilder`, `Character`)
- **Plataforma:** Exercism (Java Track)

## Descripción del Problema
Normalizar identificadores de variables mediante una función de limpieza:
1. Reemplazar cualquier espacio por `_`.
2. Convertir `kebab-case` a `camelCase` (ej. `a-bc` -> `aBc`).
3. Reemplazar dígitos en leetspeak:
   - `4` -> `a`
   - `3` -> `e`
   - `0` -> `o`
   - `1` -> `l`
   - `7` -> `t`
4. Omitir cualquier caracter que no sea una letra ni un guión bajo generado.

## Cómo ejecutar en Visual Studio / VS Code:
Abre `Main.java` y haz clic en **Run** o presiona `F5`.
